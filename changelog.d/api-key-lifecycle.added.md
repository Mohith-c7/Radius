Added managed API keys (PRD-12, part of IT-09): create/list/rotate/revoke under `/api/v1/api-keys`, scopes (`read`, `write`, `ci-upload`, `admin`) enforced on existing routes, expiry, rotation overlap, `last_used_at`, an audit trail, and HMAC-SHA256 hashed storage with a server-side `RADIUS_API_KEY_PEPPER` (migration `20261102_0015`). The static `API_KEYS` env keys still work but are deprecated and log a startup warning; see `docs/security/API_KEYS.md`.
