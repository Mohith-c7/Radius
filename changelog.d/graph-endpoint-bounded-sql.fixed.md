The dependency graph API no longer loads the whole graph to answer: `GET /analyses/{id}/graph` computes the bounded `full` or `impact` slice with database queries, so opening the Dependency graph page no longer uses seconds of CPU and can no longer make the health check time out on a small host. `GET /analyses/{id}/graph/nodes` and `/graph/edges` are now paginated (`limit`, default 500 and at most 5000, and `offset`); `data` is still an array and `meta.pagination` gives the total.
