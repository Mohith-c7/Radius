`GET /api/v1/analyses/{id}/verdict-v2` (VS-09): serves the stored Verdict v2 alpha result (per-criterion states, PR verdict, evidence quality, justification) with an `ETag`, tenant isolation, `404 disabled` / `not_computed`, and an honest `score: null` / `score_kind: "none"`; listed in OpenAPI only while `RADIUS_FEATURE_VERDICT_V2` is not `off`. CI result uploads enqueue a republish request when the flag is on. The v1 confidence response is unchanged.
