The worker now builds a pull request's dependency graph incrementally: it patches the stored graph of the nearest analysed ancestor commit (usually the previous push, or a merged pull request on the target branch), re-parsing only the changed files and the unchanged importers whose import resolution can change, instead of parsing the whole repository. The result is identical to a full build, and it falls back to a full build when there is no stored ancestor graph with the same parser and graph build fingerprint, more than `RADIUS_INCREMENTAL_MAX_CHANGED_FILES` (default 200) files changed, a tsconfig/jsconfig (or a file it extends) changed, or anything does not match. Set `RADIUS_INCREMENTAL_GRAPH=false` to always build the full graph. Graph snapshots now record a build fingerprint (`v1+<hash>`) as their version.
