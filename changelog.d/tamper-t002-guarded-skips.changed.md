Tamper T002: a runtime `pytest.skip()` under an environment guard (platform, env var, optional import, missing file, `except ImportError`) is now the low `runtime_skip_guarded`; an unconditional skip in a test new in the PR is medium (`runtime_skip_new`); a skip under another condition is medium (`runtime_skip_conditional`). Only an unconditional skip added to an existing test stays high (`runtime_skip`).
