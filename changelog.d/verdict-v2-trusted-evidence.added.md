Optional trusted CI test evidence (`RADIUS_FEATURE_TRUSTED_EVIDENCE`, default off; set it on the API and the worker): CI reports attested by the approved GitHub Actions workflow and uploaded to `POST /analyses/{id}/tests/verified-results` become `verified_provenance`, and Verdict v2 then counts only those, showing other uploads as diagnostic-only in the payload, comment, Check Run and dashboard. With the flag off nothing changes. The API image now includes the GitHub CLI for attestation verification.
