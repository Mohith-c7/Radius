Added a webhook-free GitHub path: `POST /api/v1/repositories/connect-github` connects a repository by `owner/name` (the API discovers the App installation itself), `POST /api/v1/repositories/{id}/pull-requests/{number}/analyze` analyzes one pull request by number, and `sync-pull-requests` now reports GitHub errors instead of swallowing them and skips draft pull requests. New `GITHUB_APP_PRIVATE_KEY_PATH` reads the App key from a file; the API container now receives the `GITHUB_APP_*` variables.
