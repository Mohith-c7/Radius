Coverage routes now check that the analysis belongs to the caller's organization (404 otherwise), `POST /repositories` answers 409 instead of returning or taking over another organization's repository, repository routes answer 404 for other organizations' ids, `POST /analyses` rejects a pull request of another repository and a malformed `commitSha`, and webhook errors on odd signature headers or repository ids are 4xx instead of 500. The webhook body cap default drops from 25 MiB to 5 MiB and unsigned deliveries are refused before the body is read.
