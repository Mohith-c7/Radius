The dashboard can now drive the webhook-free GitHub path: a "Connect GitHub repository" form on Repositories (owner/name, validation, API errors explained in words), an Analyze button on every open pull request, sync banners that list each skipped pull request with its reason, and a Re-run analysis button that shows API errors and links to the new analysis. Re-running an analysis of a disconnected repository is now refused with `REPOSITORY_DISCONNECTED`.
