`make dev` and `scripts/dev.ps1 dev` now start a local-development profile (`docker-compose.dev.yml`) with a randomly generated dev API key and session secret, localhost sign-in, auto-verified accounts and sign-in links in the API log, so the documented quickstart works. Plain `docker compose up` stays production-like and now requires `SESSION_SECRET` instead of falling back to a public default; the production API also refuses the published placeholder session secrets, `EMAIL_DELIVERY_MODE` now works (`smtp` or `log`, `log` is refused in production), sign-in links are no longer printed in production logs, the bundled PostgreSQL is published on 127.0.0.1 only, and the dashboard image receives its `NEXT_PUBLIC_*` values at build time. If you have an old `.env`, delete it and run `make env`.
