New opt-in worker poller: with `RADIUS_GITHUB_POLL_INTERVAL_SECONDS` set (minimum 30, default 0 = off) the worker lists open, non-draft pull requests of connected repositories and queues an analysis for every head commit that has none, so new commits are analyzed without a webhook. Bounded per tick (`RADIUS_GITHUB_POLL_MAX_ANALYSES_PER_TICK`, `RADIUS_GITHUB_POLL_MAX_REPOSITORIES_PER_TICK`), jittered, rate-limit aware, and shares its sync code (`radius_github.pull_sync`) with the `sync-pull-requests` route. The worker now stops cleanly on SIGTERM/SIGINT after the current job.
