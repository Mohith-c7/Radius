Added mutation-measured evidence strength to Verdict v2, behind `RADIUS_FEATURE_MUTATION` (default off, zero cost when off, DEC-034). The worker measures how well the linked tests detect small seeded faults in the changed Python symbols and uses the Wilson lower bound of their kill rate instead of the static assertion cap; unmeasured tests keep the static cap. Mutants run only in the hardened sandbox (`WORKER_TEST_EXECUTION_MODE=sandbox`; otherwise the analysis reports "mutation unmeasured"). The comment and dashboard show "mutation-measured (N mutants)" versus "static assertion strength only" per criterion and list the gaps found. Results are cached per repository in the new `mutation_result_cache` table (migration `20261103_0016`). Verdict contract is now `verdict-v2-contract-5` (optional fields; `evidence_basis` can also be `static_and_mutation`).
