Added a rehearsable live-GitHub demo kit: `scripts/demo_repo.py` builds a deterministic demo repository with three scripted pull requests (strong tests, weak tests, tampered tests) and prints the git commands to push it to a repository you own (it never takes a token), `scripts/demo_verify.py` runs the three scenarios through the real pipeline against a fake GitHub, `demo/EXPECTED.md` lists the expected outcomes, and `docs/DEMO_RUNBOOK.md` is the 10-minute script with a fallback.
