Repository clone URLs are now validated (https only, host `github.com` or the hosts in the new `RADIUS_GIT_ALLOWED_HOSTS`, `owner/repo` shape, no credentials) at the API and again in the worker, git is always run with `--`, only the https transport and no hooks, and the GitHub installation token is sent only to allow-listed hosts. Closes option injection through `cloneUrl` (code execution on the worker) and cross-tenant reads through local paths. Repository caches are now per organization, so existing caches are re-cloned once. Set `RADIUS_GIT_ALLOWED_HOSTS` for GitHub Enterprise Server.
