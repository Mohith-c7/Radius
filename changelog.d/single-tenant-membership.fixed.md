Single-tenant deployments can set `RADIUS_DEFAULT_ORGANIZATION_ID` (the organization the dashboard shows) so that new users join it instead of getting a personal workspace, and users still in an empty auto-created personal workspace are moved into it at their next sign-in. `RADIUS_ADMIN_EMAILS` gives verified listed addresses the admin role in that organization; nobody is demoted automatically. Without `RADIUS_DEFAULT_ORGANIZATION_ID` nothing changes.
