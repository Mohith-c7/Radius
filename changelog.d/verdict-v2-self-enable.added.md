Radius now verifies its own pull requests with Verdict v2: `.radius/intent.yml` states a few standing, test-backed criteria, `.radius/policy.yml` keeps the `Radius confidence` check advisory, and the `Radius evidence` workflow runs the same Python and dashboard test suites as CI and uploads their JUnit results, with every case named by its repository-relative test file (skipped when `RADIUS_CI_UPLOAD_KEY` is not set). The dashboard Verdict v2 panel now lists LLM suggested tests in a collapsed "Suggested tests (not run, not evidence)" section, and a verdict awaiting CI results is labelled as such instead of "insufficient evidence".
