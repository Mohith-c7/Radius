`POST /coverage` now stores coverage with the SQL backend instead of storing nothing and then failing; coverage that names a test case outside the analysed repository is rejected with 422. `GET /coverage/artifact` and `GET /coverage/symbol` now take a required `analysis_id` query parameter (checked against the caller's organization, 404 when there is no coverage) instead of reading a fixed placeholder analysis, and coverage lookups never return another analysis' report.
