`POST /repositories/connect-github` no longer attaches a discovered GitHub App installation to an organization unless `RADIUS_GITHUB_DEV_SINGLE_TENANT` is on (default on only when `RADIUS_ENV=development`); an installation linked to another organization is never taken. Webhooks are routed to the organization that owns the delivery's installation, and an unlinked installation is not linked or routed through a repository row outside single-tenant modes. Operators of multi-tenant deployments must link installations themselves; see docs/security/INSTALLATION_BINDING.md.
