The API now ships a committed OpenAPI 3.1 contract (`docs/api/openapi.json`) with stable operation ids, shared error envelopes, security schemes, examples and per-route stability levels, plus a stability and deprecation policy in `docs/api/STABILITY.md`. `scripts/export_openapi.py --check` fails when the file is stale and `scripts/openapi_diff.py` flags breaking changes to stable operations.
