Added author-trust hardening to the Verdict v2 alpha (DEC-030, `docs/security/VERDICT_V2_THREAT_MODEL.md`). Every criterion and every `.radius/intent.yml` `tests:` / `paths:` hint now carries a provenance tag (`author_pr_body`, `author_head_spec`, `base_spec`, `human_confirmed`, `llm_proposed`) through Stage A, the stored bundle, the API and the dashboard. The link strength of a `tests:` hint that only the PR author vouches for is capped at `author_hint_cap` (default 0.7) unless the identical spec file exists on the base ref or a human confirmed the criterion; criteria that rely on such a hint get the flag and reason `author_supplied_hint`, and the comment and Check Run say how many. Contract version is now `verdict-v2-contract-4` (all additions optional, older bundles still load).
