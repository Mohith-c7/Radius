# Getting help

Radius is a pre-1.0 open-source project maintained by a small team. Support is best effort with no response-time guarantee.

| I want to... | Go to |
|---|---|
| Ask a question or get help using Radius | GitHub Discussions, category **Q&A** (once Discussions is enabled, see below) |
| Share an idea | Discussions, category **Ideas** |
| Show what I built | Discussions, category **Show and tell** |
| Report a bug | [Bug report](https://github.com/Mohith-c7/Radius/issues/new?template=bug_report.yml) |
| Report a wrong verdict | [Verdict report](https://github.com/Mohith-c7/Radius/issues/new?template=verdict_report.yml) |
| Request a feature | [Feature request](https://github.com/Mohith-c7/Radius/issues/new?template=feature_request.yml) |
| Propose a rule or extractor | [Rule or extractor proposal](https://github.com/Mohith-c7/Radius/issues/new?template=rule_extractor_proposal.yml) |
| Report a security vulnerability | **Not** a public issue. See [SECURITY.md](SECURITY.md) |
| Report a conduct problem | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before you ask

1. Read the [README](README.md) and the [development guide](docs/DEVELOPMENT_GUIDE.md). Deployment and CI topics are in [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) and [docs/CI_INTEGRATION_GUIDE.md](docs/CI_INTEGRATION_GUIDE.md).
2. Search existing issues and discussions.
3. Include versions, what you ran, what you expected and what happened. Redact tokens, private repository code and personal data.
